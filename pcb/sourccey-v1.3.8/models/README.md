# Project-local 3D models

The PCB references the following project-local STEP models:

- `DRV8874PWPR.stp`
- `XT30AW-M.stp`

These files were referenced from another developer's local KiCad installation
but were not available in the source tree when this release was assembled.
Place redistributable copies at the paths above to restore those models in
KiCad's 3D viewer. Their absence does not prevent the schematic or PCB editor
from opening.
